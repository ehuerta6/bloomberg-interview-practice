# 10 — Misleading Regression Tests

**Type:** PR Review · **Difficulty:** Medium–Hard · **Target time:** 30–45 minutes

This original CIC exercise is grounded in Cappy Marketplace, not an official Bloomberg interview question.

## Scenario

A pull request says it fixes checkout totals for orders containing multiple products. The new test suite passes, but its mock replaces the code that reads the persisted order and its assertions do not establish that the saved order total equals the sum of its line totals. The proposed calculation can still lose part of a multi-product total.

## Review deliverable

Review the actual proposed diff, including the test setup and assertions. Identify actionable findings with a concrete multi-product example, the relevant persisted values, and the requirement they violate. Explain how the mock changes what code is exercised. Recommend focused counterexample tests that inspect the persisted order total and every line total. A replacement implementation is optional.

Do not duplicate the concurrent checkout retry issue or the inventory lost-update review. Focus on the arithmetic invariant and whether the tests execute and observe it.
