# 10 — Checkout Total Calculation

**Type:** Pull request review · **Difficulty:** Medium–Hard · **Target time:** 30–45 minutes

## Review request

A pull request claims to fix checkout totals for orders with multiple products. Review the implementation and tests against the persisted order data and the invariant that the order total equals the sum of its line totals.

Use a concrete multi-product example. Report actionable findings with the relevant code, test evidence, and violated requirement. Recommend focused tests that inspect the saved order and each line. Explain what the included tests exercise and leave unproven. Do not submit a replacement implementation.

Keep the review focused on total calculation and test coverage; do not duplicate the retry or inventory-adjustment reviews.
