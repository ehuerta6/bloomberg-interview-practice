# 04 — Cart Retrieval

**Type:** Pull request review · **Difficulty:** Medium–Hard · **Target time:** 30–45 minutes

## Review request

A cart retrieval change adds lookup by cart ID. Review the proposed change for access-control issues and for regressions to normal owner and administrator requests.

Use two seeded or test-created shoppers and local sample data. Report actionable findings with the file and line, triggering request, affected data or action, and evidence. Recommend focused tests for owner, other-shopper, and administrator requests, and explain what the included tests establish and leave unproven. A replacement implementation is not required.
