# 06 — Payment Error Handling

**Type:** Pull request review · **Difficulty:** Hard · **Target time:** 30–45 minutes

## Review request

Review a checkout refactor that changes how unsuccessful payment outcomes are handled. The Marketplace uses a local payment-outcome simulator.

Assess the outcome classification, HTTP responses, saved attempt state, retry and replay behavior, and order or inventory side effects against the [Marketplace API contract](../marketplace/README.md). Report actionable findings with evidence and severity. Explain what the included tests establish and leave unproven, and recommend focused assertions for the relevant outcomes. Do not design a replacement payment system.
