# 08 — Admin Order Access

**Type:** Pull request review · **Difficulty:** Medium–Hard · **Target time:** 30–45 minutes

## Review request

Review a refactor that moves administrative authorization checks from a shared router boundary to endpoint handlers. Assess the changed routes for access-control and regression risks.

Report actionable findings with the endpoint, caller identity, affected data, and code or test evidence. Explain what the included administrator tests establish and leave unproven. Recommend focused tests for administrator, shopper, unknown, and missing identities. A replacement implementation is not required.
