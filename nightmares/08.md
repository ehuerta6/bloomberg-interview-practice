# 08 — Admin Authorization Regression

**Type:** PR Review · **Difficulty:** Medium–Hard · **Target time:** 30–45 minutes

This original CIC exercise uses the fictional local admin and shopper identities only.

## Scenario

A refactor moves an administrative authorization check from a shared router boundary onto individual endpoint handlers. Authorized administrator requests continue to work, and the added tests pass, but one order-detail path is missing the check. A shopper may retrieve administrative order data.

## Review deliverable

Inspect the exact proposed diff. Identify actionable permission-boundary findings with endpoint, caller identity, data exposed, and code/test evidence. Assess what the authorized-admin tests establish and why they do not prove rejection of shopper, unknown, or missing identities. Recommend focused unauthorized-request tests. A replacement implementation is optional.
