25 · Rolling Analytics Window

PR: Sum events inside a rolling window

Summary

An analytics endpoint reports a metric over a trailing duration. Review whether its endpoints, future events, and malformed inputs are handled consistently.

Input and output

rolling_total(events, now, window_seconds) accepts timestamped numeric events, a reference datetime, and a nonnegative window duration. It returns the sum of included values.

Expected behavior and invariants

  • Include timestamps in the closed interval [now - window, now]; exclude older and future events.
  • Count negative event values as supplied. An empty window sums to zero.
  • Reject invalid event timestamps or values and negative, boolean, or nonnumeric window lengths.
  • Event and reference timestamps must both be timezone-aware or both naive.

Review task

Test events at each endpoint, just outside the interval, negative values, zero-length windows, and timestamp timezone mismatches.
